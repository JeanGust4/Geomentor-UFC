# 🌋 GeoMentor UFC - Tutor de IA em Geologia

O GeoMentor é um agente de Inteligência Artificial integrado no Telegram, desenvolvido para atuar como tutor e mentor socrático exclusivo para estudantes de Geologia da Universidade Federal do Ceará (UFC).

## ⚙️ Arquitetura e Tecnologias
- **Plataforma:** Coze
- **LLM Base:** GPT-4o-mini (Suporte Multimodal)
- **Interface:** Telegram Bot API
- **Técnica:** Prompt Engineering Avançado + RAG (Base de Conhecimento Curricular)

## 🧠 Funcionalidades Principais
- **Método Socrático:** O agente nunca fornece respostas diretas, forçando o aluno a pensar criticamente.
- **Análise Visual (Visão Computacional):** Recebe fotografias de rochas, minerais e afloramentos e guia o utilizador no processo de identificação.
- **Diagnóstico Adaptativo:** Ajusta a complexidade das perguntas com base no semestre atual do estudante (Iniciante a Avançado).

## 📂 Estrutura deste Repositório
- `system_prompt.md`: O cérebro comportamental do agente e regras de trava pedagógica.
- `knowledge_base_ufc.md`: O mapeamento estruturado da matriz curricular de Geologia da UFC.
